# 图片识别提示词模板（Qwen-VL）

> 用途：让 Qwen3-VL 识别用户发来的图片（截图 / 照片 / 图表等）。
> 原则：**按需取用，不照搬**。图片简单就用简版，图片复杂或用户要求"详细"才上详版。
> 每次发送前根据图片类型、用户问题、上轮已给信息做裁剪/增补。

---

## 一、详版（复杂截图 / 用户要细节 / 界面分析）

```
你是专业的图片分析助手。请对这张图片进行系统、详尽的分析，按以下结构回答：

【1. 图片类型】
这是截图 / 照片 / 图表 / 插画 / 文档扫描中的哪一种？

【2. 整体内容概述】
用 2-3 句话概括图片在展示什么。

【3. 关键元素清单】
- 文字内容：逐条列出所有可见的文字（标题、正文、按钮、标签、数字等），尽量原文引用
- 界面/视觉元素：按钮、菜单、图标、弹窗、状态指示（如圆点、对勾、感叹号）及其状态
- 布局结构：元素之间的位置关系（顶部/左侧/居中）、嵌套层级、分组

【4. 细节与状态】
- 任何高亮、选中态、边框颜色、禁用状态等视觉状态
- 图标或符号的含义推断

【5. 位置与坐标（如适用）】
对可点击或关键元素，给出大致位置描述（如"右上角""左侧导航第二个"）

【6. 不确定项】
对看不清或无法确认的部分，明确说"不确定"，不要编造。

要求：宁全勿缺，宁可多列也不要漏掉重要细节；文字尽量原文照抄，不概括不翻译。
```

**适用**：软件设置页、复杂仪表盘、长文截图、报错弹窗排查、用户明确要求"详细描述"

---

## 二、标版（日常图片 / 默认档）

```
请描述这张图片：这是什么？主要展示了什么内容？如有文字请列出关键部分。不确定的地方请说明。
```

**适用**：大多数日常图片，回答 3-5 句话即可

---

## 三、简版（快速问答）

```
用一句话回答：这张图里有什么？
```

**适用**：用户只想知道"这是啥"、快速确认类问题

---

## 四、定向版（用户有具体问题）

直接围绕用户的问题问，不套通用结构：

```
只看这张图：{用户的具体问题}。请只回答与问题相关的内容，不要展开无关细节。
```

**适用**：看图找错误、找按钮、读数字、对比两张图、翻译图中文字等

---

## 调整原则

1. **先判断用户意图**：随便问"这是啥"→ 简版/标版；排查问题/要细节 → 详版
2. **只关注相关区域**：用户问图中某部分时，聚焦该部分，不啰嗦其他
3. **上下文已有信息不重复**：之前已经描述过的图片，后续问题只说增量
4. **不确定就直说**：看不清/识别不了的，明确标注，绝不编造
5. **翻译/总结需求**：用户要翻译图中文字或总结要点时，按需调整输出格式（如分条列出原文+译文）
